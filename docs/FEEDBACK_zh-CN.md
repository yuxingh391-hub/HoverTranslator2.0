# HoverTranslator · 问题反馈指南

HoverTranslator 正在准备 Windows 离线 Portable 发行。请通过 GitHub Issues 提交可复现的问题：

[打开 GitHub Issues](https://github.com/yuxingh391-hub/HoverTranslator2.0/issues/new/choose)

## 建议提供的信息

- 使用版本（例如 `v0.7.21-rc.1`；以实际版本为准）
- Windows 版本和系统架构（例如 Windows 11 x64）
- 问题类别：启动、OCR、单词翻译、整句翻译、词库、设置保存、性能或其他
- 是否离线、使用哪种输入方式（Ctrl/Alt + Hover）
- 可以重现问题的操作步骤、预期结果、实际结果
- 适当裁剪、打码的错误截图

**隐私提醒：** 请勿粘贴完整私人文档、包含密码/令牌的日志、个人术语库、账号信息或未打码的屏幕截图。OCR 日志可能包含屏幕上的原文。涉及安全告警时，请提供检测名称和文件 SHA-256，不要求关闭安全软件。

目前公开仓库是产品展示与未来发行入口，并非源码仓库。请勿通过 Issue 请求私有源码或假定尚未发行的版本可以公开下载。
